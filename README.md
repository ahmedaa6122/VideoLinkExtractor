# VideoLinkExtractor

متصفح Android مدمج مع مستخرج عام لروابط الوسائط.

## المزايا
- تصفح المواقع داخل WebView.
- منع النوافذ المنبثقة و`window.open` وJavaScript dialogs.
- حجب مجموعة من نطاقات ومسارات الإعلانات الشائعة.
- عدم تشغيل الفيديو تلقائيًا؛ التطبيق يحاول استخراج الرابط مباشرة من DOM وطلبات الشبكة وPerformance resources.
- FAB يظهر عدد الروابط المستخرجة.
- الضغط على FAB يفتح Bottom Sheet تحتوي الروابط مع النسخ والمشاركة.
- دعم MP4 وWebM وM4V وMOV وMKV وAVI وM3U8 وMPD وMPEG-TS.

## القيود
- روابط `blob:` و`data:` يتم تجاهلها لأنها ليست روابط ملفات مباشرة.
- المواقع التي تستخدم DRM أو تشفيرًا أو مشغلات تعتمد على Media Source Extensions قد لا توفر رابطًا مباشرًا قابلًا للاستخراج.
- لا يتم تجاوز DRM أو أنظمة الحماية.
- حجب الإعلانات يعتمد على قائمة نطاقات/مسارات، لذلك لا يمكن ضمان إزالة كل إعلان من كل موقع.
