# VideoLinkExtractor

تطبيق Android عام لاكتشاف روابط الوسائط التي تطلبها صفحات الويب داخل WebView.

## المدعوم
- MP4
- WebM
- M4V
- MOV
- M3U8 / HLS
- MPD / DASH
- MPEG-TS

## طريقة العمل
1. أدخل رابط صفحة الفيديو.
2. اضغط فتح.
3. شغّل الفيديو داخل الصفحة.
4. التطبيق يراقب طلبات WebView وموارد JavaScript.
5. عند اكتشاف رابط وسائط يظهر في القائمة.
6. اضغط نسخ أو مشاركة.

## ملاحظات
- روابط `blob:` لا تمثل عادةً رابط ملف مباشر، لذلك يتم تجاهلها.
- بعض المواقع تستخدم DRM أو تشفيرًا أو مشغلات مخصصة، وقد لا توفر رابطًا قابلًا للاستخراج.
- التطبيق لا يتجاوز DRM أو أنظمة الحماية.
- `usesCleartextTraffic=true` موجود لدعم بعض المواقع القديمة التي تستخدم HTTP؛ يمكن تعطيله إذا لم تكن بحاجة إليه.

## فتح المشروع
افتح مجلد `VideoLinkExtractor` في Android Studio ثم Sync Project with Gradle Files.
